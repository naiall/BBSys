ตั้งค่าเชื่อมต่อ Google Sheets
1
สร้าง Google Spreadsheet
สร้าง Spreadsheet ใหม่ → คัดลอก ID จาก URL
docs.google.com/spreadsheets/d/SPREADSHEET_ID/edit
2
วางโค้ด Code.gs ใน Apps Script
Extensions → Apps Script → วาง Code.gs → แก้ SPREADSHEET_ID → Save → รัน initSheets() ครั้งแรก
3
Deploy → Web App
Deploy → New deployment → Web App
Execute as: Me | Who has access: Anyone → Deploy → Copy URL
4
วาง Web App URL ด้านล่าง
5
GitHub Pages
Upload index.html → Settings → Pages → Branch: main → Save
QR URL จะเป็น:
https://username.github.io/repo/?scan=SN-001
